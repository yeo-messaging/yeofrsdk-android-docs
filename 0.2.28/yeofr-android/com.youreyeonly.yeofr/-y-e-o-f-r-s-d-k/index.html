YEOFRSDK

object YEOFRSDK

Main entry point for the YEO Face Recognition SDK.

This singleton manages the face recognition engine lifecycle, including initialization, tracker management, face enrollment, face detection and the passive liveness check.

Typical usage:

YEOFRSDK.init(context)
val result = YEOFRSDK.detectFaces(params)
