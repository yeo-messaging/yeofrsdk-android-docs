val buffer: ByteArray

the frame's pixels. Either raw ARGB32 — exactly scanline * height bytes of Bitmap.Config.ARGB_8888 pixels as Bitmap.copyPixelsToBuffer writes them, the fastest handoff — or an encoded image (JPEG/PNG) of any other size, which the engine decodes. Raw is recognised purely by size.
