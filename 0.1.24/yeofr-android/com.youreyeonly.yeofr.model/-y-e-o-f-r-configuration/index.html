YEOFRConfiguration

data class YEOFRConfiguration(val internalResizeWidth: Int = 410, val frSDKThreshold: Double = 0.987566, val faceRecognitionTrackerMemoryLimit: Int = 4000, val keepFaceImagesInTracker: Boolean = true, val faceDetectionThreshold: Int = 5, val arbitraryRotation: Boolean = true, val numberOfThreads: Int = 1)

Configuration for the YEO Face Recognition SDK.

Controls face detection sensitivity, recognition thresholds, tracker memory limits, and threading. Pass to YEOFRSDK.configureFRSDK or set on YEOFRSDK.config.

val faceRecognitionTrackerMemoryLimit: Int

The memory size is measured in the total number of facial appearances stored (about 11 Kbytes per appearance when the KeepFaceImages parameter is set to true, and about 1.5 Kbytes when set to false). By default, the limit is 2000 appearances (about 24 Mbytes or 3 Mbytes depending on the value of the KeepFaceImagesInTracker parameter).

val keepFaceImagesInTracker: Boolean

When the KeepFaceImages parameter is set to true, Tracker API stores an original facial image along with every facial appearance in the Tracker memory. The size of a facial appearance is about 1.5 Kbytes when KeepFaceImages is set to false, and about 11 Kbytes when KeepFaceImages is set to true. By default is set to false.
