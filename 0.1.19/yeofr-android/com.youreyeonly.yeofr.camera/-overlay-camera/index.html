OverlayCamera

@RequiresApi(value = 23)
class OverlayCamera(val overlayView: OverlayView) : LifecycleOwner

Manages the front-facing camera lifecycle tied to an OverlayView.

Binds a CameraX preview and image analysis pipeline to the overlay view. Automatically transitions the overlay between positive and negative states based on userFaceOnlyDetected emissions.

Requires API 23+.
